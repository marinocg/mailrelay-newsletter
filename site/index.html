WooCommerce (Premium) — in development

In development Premium

Add compliant opt-in at checkout and sync customers to Mailrelay without slowing down checkout.

What it includes (v1)

Launch essentials (Pro v1)

  • Enable/disable Woo integration + health status
  • Checkout opt-in checkbox (Classic + Blocks)
  • Subscribe triggers (processing/paid/completed) + guest support
  • Field mapping (email, name, phone, country)
  • Group routing rules (base group + product/category rules)
  • Order-level observability (per-order sync status + logs)
  • Compliance defaults (explicit opt-in + store consent evidence)

Next wave (v1.1+)

  • Thank-you page fallback modal (for express/one-click flows if consent missing)
  • Customer preference page ("My Account" marketing opt-in)
  • Lifecycle enrichment fields (order_count, total_spent, last_order_date)
  • Bulk backfill tool (sync past customers)
  • Abandoned cart signals (automation triggers)
Pro feature that drives ROI: better targeting + automations + deliverability at scale.
